# The Stop-Loss That Worked Too Well

One original line about crypto/trading life (148 characters) for the
Laugh Track bounty. The joke: a stop-loss set to protect a trade gets
hunted by the market in seconds — the only thing in the portfolio that
ever executed perfectly.

`main.ts` (Node 22, standard library only) validates the line against the
gate (1–200 characters, a single non-blank line) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads the file
back to confirm the write is byte-identical. No network, no randomness,
no clock: two runs produce byte-identical output.
